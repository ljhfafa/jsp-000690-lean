# JSP-000690: independent Lean formalization

Work in progress. No verification pass or award priority is claimed.

Original mathematical solution: Ruiliang Li, *On an Erdős–Lovász problem:
3-critical 3-graphs of minimum degree 7*, arXiv:2512.24850 (2025).

The project independently encodes the published finite construction and will prove
the exact chromatic-critical existence statement, including all proper subhypergraphs.
Earlier complete-looking public formalizations have been identified; this project
does not claim first formalization. See PROGRESS.md and the competition evidence.

Lean 4.32.0, with its bundled standard library; no Mathlib or external dependency.

OpenAI Codex autonomously performed the research, implementation, debugging and
verification under the direction of the repository owner. The owner commissioned
and directed the project; no claim of manual proof authorship or mathematical
discovery by the owner is made.
